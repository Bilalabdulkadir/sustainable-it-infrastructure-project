🌿 Sustainable IT Infrastructure Project

This project demonstrates how Green IT principles can reduce the environmental impact of digital infrastructure while improving operational efficiency.

It combines IT infrastructure management, data analytics, cloud optimization, and AI-driven insights to measure and improve sustainability performance.

Key areas:
- ⚡ Energy efficiency and power optimization
- ☁️ Cloud resource optimization
- ♻️ E-waste reduction and hardware lifecycle management
- 📊 Sustainability KPI tracking and analytics
- 🤖 AI-powered Green IT recommendations

Technology Stack:
- Python
- SQL/PostgreSQL
- Power BI / Looker Studio
- React
- TypeScript
- AI-assisted sustainability analysis

Project Goals:
- Reduce unnecessary energy consumption
- Extend IT asset lifespan
- Improve resource utilization
- Support climate-conscious digital transformation

# Contributing to the Sustainable IT Infrastructure Project

Thanks for your interest in contributing! This file explains how to propose changes, report issues, and submit pull requests.

How to contribute
- Open an issue to discuss large or breaking changes before implementing them.
- Fork the repository and create a branch named descriptively, e.g. `feat/gcp-cost-optimizations` or `fix/ci-lint`.
- Keep changes small and focused. Add tests or examples where helpful.
- Follow conventional commits for commit messages (e.g., `feat:`, `fix:`, `chore:`).
- Submit a pull request and fill the PR template.

Issue guidelines
- Use the issue templates for bug reports and feature requests.
- Provide reproduction steps, expected vs actual behavior, and environment details for bugs.

Pull request guidelines
- Link related issues in the PR description.
- Describe what, why, and any relevant design decisions.
- Keep the PR scope focused; break large work into smaller PRs when possible.
- Assign reviewers and address review feedback promptly.

Community
- Share sustainability ideas and proposals via the repository’s Discussions:
  https://github.com/your-org/your-repo/discussions

Thank you for helping improve sustainable IT practices!
